Request a demo token
  TOKEN=$(curl -s -X POST http://localhost:9000/oauth2/token \
    -H 'Content-Type: application/x-www-form-urlencoded' \
    -d 'grant_type=client_credentials' \
    -d 'client_id=demo-client' \
    -d "client_secret=${DEMO_SECRET}" \
    -d 'scope=read write' | sed -n 's/.*"access_token":"\([^"]*\)".*/\1/p')

  curl -i -H "Authorization: Bearer ${TOKEN}" http://localhost:8080/api/get

WARNING: identity.autoscaling is enabled with a PVC-backed key. Only a
ReadWriteMany volume or a shared read-only Secret safely serves multiple
replicas. ReadWriteOnce volumes are single-writer and cannot be attached by pods
on different nodes. Prefer identity.keys.existingSecret for replicas.

Security notes
  - Both containers run as UID/GID 65532 with a read-only root filesystem.
  - This chart does not terminate TLS. Put an Ingress/mesh in front and set
    identity.issuer to the external issuer URL.
  - Rate limits and circuit breakers are per gateway pod, not global.
  - NetworkPolicy is {{ if .Values.networkPolicy.enabled }}enabled{{ else }}disabled{{ end }}; enable it for default-deny gateway/identity traffic.
